## About

**Nexora Institute of Computing (NIC)** is an open-source Computer Science & Engineering curriculum built entirely on GitHub. Every subject is a repository you can read, fork, learn from, and improve.

We rebuilt the traditional 8-semester CSE programme as **102 repositories** - each one containing the theory, labs, projects, and assessments that a real course would need.

## What we publish

| Category | Count | What it is |
| :--- | :---: | :--- |
| **Official curriculum** | **80 subjects** | 8 semesters - theory, labs, projects. From Programming Fundamentals to Major Project. |
| **Advanced courses** | **6** | Post-graduate depth - Quantum Computing, Advanced Compilers, Database Internals, Distributed Consensus, Post-Quantum Crypto, Formal Verification. |
| **Alternate editions** | **4** | Same topic, different language - Data Structures in Python & Java, ML in PyTorch, Systems in Rust. |
| **Workshops** | **6** | Short, self-paced - Docker, Git Mastery, Vim/Emacs, Regex, GraphQL, System Design Interview. |
| **Specialisation tracks** | **4** | Curated routes - ML Engineer, Full-Stack Engineer, Security Engineer, Cloud Architect. |

## Mission

> *To make world-class Computer Science education open, practical, and accessible to every learner - regardless of geography, income, or formal enrolment.*

## Our story

Nexora began with a simple frustration: the best CS curriculum in the world is usually **free in content but closed in structure**. Lecture notes exist. Tutorials exist. Textbook PDFs exist. But a coherent, semester-by-semester map that ties them together is almost never public.

So we rebuilt the traditional CSE programme as **repositories**. Every semester is a folder. Every subject is a repo. Every lab is code you can run.

## Contributing

Every repository welcomes contributions - fix a typo, add a lab, improve a project brief, or suggest a new elective.

1. **Find a subject** you want to improve.
2. **Fork** the repository.
3. **Open a pull request** with a short description of what you changed and why.

Read the full [Contributing Guide](https://github.com/Nexora-Institute-of-Computing-NIC/.github/blob/main/CONTRIBUTING.md) and [Code of Conduct](https://github.com/Nexora-Institute-of-Computing-NIC/.github/blob/main/CODE_OF_CONDUCT.md).

## Disclaimer

> Nexora Institute of Computing is an **open-source curriculum project**. It is **not a UGC-recognised university** and **does not award accredited degrees**. All content is provided for self-directed learning.
