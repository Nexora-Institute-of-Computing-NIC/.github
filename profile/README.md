## 📖 About

**Nexora Institute of Computing (NIC)** is an open-source Computer Science & Engineering curriculum that lives entirely on GitHub. Every subject, every lab, every project — is a repository you can read, fork, learn from, and improve.

We believe that a rigorous CS education should not be locked behind a paywall or a campus gate. So we rebuilt the traditional 8-semester CSE programme as 80 public repositories, each one containing the theory notes, hands-on labs, assignments, project briefs, and assessments that a real course would need.

Whether you are a self-taught developer filling gaps, a student supplementing your degree, or a teacher looking for open course material — you are welcome here.

---

## 🎯 Our Mission

> *To make world-class Computer Science education open, practical, and accessible to every learner — regardless of geography, income, or formal enrolment.*

We pursue this by:

- **Publishing a full 8-semester CSE curriculum** as open repositories, not locked PDFs.
- **Pairing every theory module with a hands-on lab**, because computing is learned by building.
- **Keeping content version-controlled** so anyone can trace how a subject evolved and contribute improvements.
- **Designing for self-directed learners**, with clear prerequisites, difficulty levels, and learning outcomes on every subject page.

---

## 🌟 Our Vision

> *A world where a motivated learner in any city, town, or village can follow the same CSE path as a student at the best engineering college — and prove it through their public GitHub work.*

We are building toward a future where:

- **Portfolio replaces pedigree.** What you have built and published matters more than which campus you attended.
- **Curriculum is a living document.** Subjects improve continuously through community pull requests, not once-a-decade syllabus revisions.
- **Industry and academia meet in the open.** Labs reflect the tools and practices engineers actually use, not the tools of a decade ago.

## 📜 Our Story

Nexora Institute of Computing began with a simple frustration: **the best CS curriculum in the world is usually free in content but closed in structure.** Lecture notes exist, YouTube tutorials exist, textbook PDFs exist — but a coherent, semester-by-semester map that ties them all together is almost never public.

So a small group of engineers and educators decided to build the thing we wished had existed when we were learning: a **GitHub-native university** where every semester is a repository, every subject is a folder, and every lab is code you can run.

We started with the premise that a curriculum is not a building — it is a *structure of knowledge*. Once you model it as repositories, a few powerful things become true:

- **It is transparent.** Anyone can audit what is taught.
- **It is forkable.** You can adapt the whole programme to your own context.
- **It is improvable.** A typo fix, a better lab, a new elective — all arrive as pull requests.
- **It is permanent.** No site goes down; no content disappears.

Today NIC publishes **8 semesters · 80 subjects · theory + labs + projects** — from Programming Fundamentals in Semester 1 to a Major Project and Thesis in Semester 8. It is not a degree, and it never claims to be one. It is something we think is more useful: a **complete, honest, openly maintained CS education** that anyone can start today.

## 🤝 Contributing

Every subject repository welcomes contributions: fix an error, add a lab, improve a project brief, suggest a new elective. If you are new, look for issues tagged **`good first issue`**.

1. Fork the subject repository you want to improve.
2. Make your change on a new branch.
3. Open a pull request with a short description of what you changed and why.
