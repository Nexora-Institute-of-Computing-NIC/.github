# Nexora Institute of Computing

Open-source Computer Science & Engineering curriculum — 8 semesters, hybrid theory + practical labs.

> **Disclaimer:** Nexora Institute of Computing is an open-source curriculum project. It is not a UGC-recognised university and does not award accredited degrees.
