# Contributing to Nexora Institute of Computing

Thank you for your interest in improving our open CSE curriculum. Every contribution — from a typo fix to a full lab — makes this project better for every learner.

## How You Can Contribute

- **Fix errors** in theory notes, labs, or assignments
- **Add labs** with runnable starter code and tests
- **Improve project briefs** and rubrics
- **Suggest new electives** by opening an issue
- **Report broken links** or outdated content

## Workflow

1. **Fork** the subject repository you want to improve.
2. **Create a branch** from `main` (e.g. `fix/lab-03-typo` or `feat/lab-11-recursion`).
3. **Make your change** and test it locally.
4. **Open a pull request** against `main` with a short description of *what* changed and *why*.
5. A maintainer will review and merge.

## Content Guidelines

- **Every lab must include** a `README.md`, runnable `starter/` code, and a `tests/` folder with at least one passing test.
- **Every theory module must include** learning objectives, worked examples, and a short exercise set.
- **Language**: clear, concise, professional English. Avoid jargon without explanation.
- **File naming**: lowercase with hyphens (`lab-01-hello-world.md`, not `Lab 1 Hello World.md`).
- **Markdown**: use ATX headings (`##`), fenced code blocks with language tags, and relative links to other files in the same repo.

## Commit Messages

Use short imperative messages:

- `Add lab 11: recursion practice`
- `Fix typo in module 3 notes`
- `Update project rubric to include testing weight`

## Code of Conduct

By participating, you agree to follow our [Code of Conduct](./CODE_OF_CONDUCT.md).
